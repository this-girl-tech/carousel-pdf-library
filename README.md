# Carousel PDF Library

Downloadable PDFs of beginner-friendly tech carousels by **this.girl.tech**.

These are designed to make tech concepts easier to understand and revisit. Each PDF contains the slides from a carousel posted on Instagram.

## Browse the PDFs

PDFs are organized by topic. Open a folder and select a PDF to view or download it.

- `software-engineering/`
- `networking/`
- `system-design/`

More topics will be added over time.
